About the Lab

We build the systems that let AI run Faster, stay Future-pROOf, and remain Trustworthy. From observability that sees everything to infrastructure that survives anything, the FROOT Lab turns hard problems in systems, networking, and security into infrastructure the next generation of AI can rely on.

FROOT

Future-Proof, Trustworthy Telemetry for high-performance, high-availability networks.

ONSET

Optics-enabled network defenses against extreme terabit-scale DDoS attacks.

AI for Cloud Ops

Scalable, automated diagnosis of performance, resilience, and security problems in modern CI/CD.
